# ☸️ آموزش کوبرنتیز: از اعماق لینوکس تا مقیاس پروداکشن

به مستندات جامع دوره **Kubernetes Deep Dive** خوش آمدید.
این مجموعه متفاوت از آموزش‌های معمولی است؛ ما اینجا یادگیری را از دستورات `kubectl` شروع نمی‌کنیم، بلکه ابتدا به **"زیر کاپوت"** سیستم‌عامل می‌رویم تا بفهمیم کانتینرها واقعاً چگونه کار می‌کنند و سپس لایه‌به‌لایه بالا می‌آییم تا به مدیریت کلاسترهای پیچیده برسیم.

## 🎯 هدف این دوره
*   **درک عمیق (Deep Dive):** کالبدشکافی مفاهیم به جای حفظ کردن دستورات.
*   **رویکرد پایین به بالا (Bottom-Up):** شروع از مفاهیم پایه سیستم‌عامل و شبکه، رسیدن به کانتینر ران‌تایم‌ها و در نهایت ارکستراسیون.
*   **آمادگی برای پروداکشن:** تمرکز بر روی سناریوهای واقعی، امنیت، و پایداری سیستم.

## 📚 پیش‌نیازها
*   ✅ آشنایی مقدماتی با دستورات لینوکس (LPIC-1 سطح دانش)
*   ✅ دسترسی به یک ماشین لینوکسی (VirtualBox یا VPS) برای تمرینات
*   ✅ اشتیاق برای یادگیری مفاهیم Low-Level

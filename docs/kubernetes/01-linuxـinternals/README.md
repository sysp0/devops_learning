# 🐧 جلسه اول: کالبدشکافی لینوکس و پروسه‌ها

به مستندات **جلسه اول** خوش آمدید.
در این جلسه، ما سفری عمیق به هسته لینوکس داشتیم تا بفهمیم "زیر کاپوت" سیستم‌عامل چه می‌گذرد. هدف ما عبور از لایه سطحی و درک نحوه مدیریت پروسه‌ها، تصمیم‌گیری‌های CPU و چگونگی ایجاد محیط‌های ایزوله (پایه کانتینرها) است.

ما در این مستندات یاد می‌گیریم که چرا سیستم کند می‌شود، پروسه‌های زامبی از کجا می‌آیند و چگونه می‌توانیم بدون داکر، محیطی ایزوله بسازیم.

---

## 📚 سرفصل‌های پوشش داده شده (Syllabus)

مباحث موجود در این مستندات شامل موارد زیر است:

### 🧠 مدیریت پردازش و زمان‌بندی (Process Management)
*   **CPU Scheduling:** الگوریتم‌های تصمیم‌گیری کرنل (مثل CFS و Round Robin) برای اجرای برنامه‌ها.
*   **Context Switching:** هزینه‌های پنهان جابجایی بین پروسه‌ها و انواع سوئیچ‌های داوطلبانه/اجباری.
*   **Process Lifecycle:** تولد پروسه با `fork()`، مفهوم پروسه‌های Zombie و Orphan و نقش `init`.

### 📊 تحلیل و پایش سیستم (System Internals & Monitoring)
*   **Performance:** تحلیل دقیق `Load Average` و تشخیص گلوگاه‌های دیسک (I/O Wait).
*   **Kernel Interfaces:** درک تفاوت `User Space` و `Kernel Space` و استفاده از `/proc` و `/sys` برای استخراج اطلاعات.

### 🛡️ مقدمات کانتینر (Container Primitives)
*   **Namespaces:** آشنایی با مفهوم ایزوله‌سازی در لینوکس.
*   **Container Tools:** استفاده عملی از دستورات سطح پایین `unshare` و `nsenter` برای ساخت و دیباگ محیط‌های ایزوله.
